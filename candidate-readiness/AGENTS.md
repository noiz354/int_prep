# Candidate Readiness & Coaching Agent Guide

Read the PRD, feature catalog, and UAT plan before changing this bounded context.

## Required skills

- `candidate-readiness-coaching`
- `candidate-portal-accessibility`
- `react-experience`
- `api-auth-security`
- `ai-governance`
- `testing-quality`
- `dependency-security`
- `documentation-progress`

## Non-negotiables

- Treat all sessions as preparation-only. Reject any `live_assessment` or equivalent context.
- Do not copy hiring-evaluation data into readiness records by default.
- Do not auto-recommend hire/no-hire, infer protected traits, or market a guaranteed outcome.
- Keep candidate sharing granular and candidate-controlled.
- Do not install providers or dependencies without an approved source, license, security review, and test plan.
